# 图片编辑：蒙版局部生成

仅加线条、文字或箭头时，使用原图加透明标注层；确需生成局部内容时，才使用局部生成。复制下方完整提示词，填写输入项；参考图不是必填项。

```text
请按以下约束进行局部编辑。

输入与目标：
- 唯一原始底图：【精确文件或附件】。
- 编辑位置与内容：【填写位置、对象和具体改动；仅标注时写明线条/文字/箭头、颜色与粗细】。
- 参考材料（可选）：【仅用于定位或外观参考，不作为底图】。
- 输出位置及覆盖要求：【默认另存；已有明确覆盖授权时填写精确交付路径】。

编辑前：
从指定原件独立回源，记录文件SHA256（字节指纹）、尺寸、方向和色彩信息；区分原件、截图、模型输入、历史稿与副本。先用已有材料核对目标和原图坐标，截图只作定位参考。原件身份或坐标不清时，仅暂停相关编辑并说明缺口。

按目标选择方法：
1. 仅加线、文字或箭头：在独立透明层上确定性绘制，再合成到原图。允许修改区仅为实际笔画及其抗锯齿覆盖；圈出的内部、面部和其他底图像素仍受保护。不得用整图生成绘制这些标注。改旧标注时，从保全的原始底图重新合成，不在上次合成图上反复擦除或重绘。
2. 确需生成局部内容：先明确获准修改区域，再在该区域生成或生成局部素材后蒙版合成。生成工具不能提供或验证明确蒙版时，使用可验证的局部素材合成；无法满足时仅暂停该编辑，说明最小恢复条件。

蒙版与保真：
编辑前确定允许区及边缘支持范围，记录位置、形状和必要参数；蒙版外像素必须与原始底图完全一致。抗锯齿或必要羽化也计入允许区，不得为包住意外变化事后扩大蒙版。仅标注时不因“自然衔接”扩大笔画覆盖，更不能把整个圈内划成可修改区。
保持原图尺寸和坐标，除明确获准区域与内容外，不缩放、重采样、平移、美颜、磨皮、锐化、调色或改变光照、背景、面部结构与细微纹理。

文件与参数：
保全原始文件字节。文件字节一致、解码后像素一致、元数据与编码参数保留是不同承诺，分别核验和报告。JPEG重编码不能保证未改区域像素零变化；有此要求时采用无损合成输出。
若要求“所有原始参数不变”，保留原文件，并交付独立透明层及另存的无损合成预览，说明预览的元数据/格式限制；不能宣称添加内容后的单一文件仍与原件字节完全相同。

交付前验证：
1. 独立重新读取指定原件与实际输出，使用同一解码方式和一致的方向/色彩处理，核尺寸及坐标对应；逐像素核对蒙版外变化数必须为0，不能只凭肉眼或旧AI的PASS。
2. 保存原件、蒙版和输出的SHA256，记录允许区、实际改变像素数量与位置、解码方式及未验证项。另看原生局部对照，检查线条位置与形状；像素保真不证明专业边界正确。
3. 默认另存。已有明确授权的精确交付路径在检查通过后覆盖，不重复索取相同许可；原始底图仍保全。目标或权限不清只暂停覆盖。
4. 检查不通过，不作为完成稿交付；报告实际问题、证据和下一行动。无法完成必要验证时明确标为未验，不用“看起来一致”冒充通过。
```
