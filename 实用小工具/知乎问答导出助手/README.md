# 知乎只读导出：使用与资料入口

[English](README.en.md)

版本：0.6.7。ChatGPT Workflows 中免费、有限维护的本地浏览器扩展，需手动安装；没有上架浏览器商店，也不保证每个问题都能全量导出。

## 为什么研发这个工具？

知乎一个问题可能有很多回答，每篇回答还有评论和楼中楼。逐条打开、展开和复制很费时间，也容易漏掉回复。网站有时会把问题标题链接直接打开为某一篇回答，普通使用者很难判断自己到了哪种页面。

本工具让使用者在问题页或回答页选择采集范围，把正常返回的文字资料保存为本机JSON文件，供自己留存、检索或进一步分析。JSON是一种按字段组织的文本文件；它不是已经排好版的文章，工具也不内置AI总结。

## 解决了什么问题？

- 不需要自己寻找问题总页。打开任意一篇回答，也可以选择检索整个问题。
- 只有两个采集选项，不需要从不完整的预载回答下拉框中选作者。
- 自动翻页读取正常返回的回答、评论和楼中楼，按ID去重，并检查回复数量及上下级关系。
- 清楚区分核齐、仍有缺口和提前停止；不把“遍历结束”说成网站的所有内容都拿到了。
- 结果保存到本机，不上传；不点赞、关注、发帖或发评论。

## 怎样安装？

普通使用者不需要安装Node或Python，也不用运行测试命令。

1. 下载并解压本仓库，或使用已有的仓库副本，放到以后不会随便删除的位置。不要直接在ZIP里打开源码。
2. 在Chrome打开 `chrome://extensions`，或在Edge打开 `edge://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择资料包中的 `extension` 文件夹。应选择直接包含 `manifest.json` 的文件夹，而不是资料包最外层。
4. 在扩展详情确认版本为0.6.7，可以将扩展固定到工具栏。若出现红色报错，暂停使用，把不含账号隐私的错误截图交给维护者。

其他兼容Chrome扩展的浏览器可能可用，但尚未逐一实测。升级时先取得新版文件并保留旧目录和结果文件，重新加载扩展，再刷新已经打开的知乎标签。“重新加载”只读取本机所选目录，不会从维护者处自动下载更新。停用或移除扩展后也应刷新已经注入工具的标签。

## 怎样检索？

1. 像平时一样打开知乎中的一个问题或一篇回答。话题页、首页和搜索列表同时包含多个问题，先点进想看的那一项即可。
2. 点击工具栏里的本扩展。右下角出现题目和两个选项；此时还没有发送采集请求，不想用可点右上角×。
3. 选择范围：

| 选项 | 采集内容 |
| --- | --- |
| 1. 检索这个帖子的原文以及当前的这一篇回答 | 问题原文、当前回答及其正常返回的评论和楼中楼 |
| 2. 检索这个帖子的原文以及所有的回答 | 问题原文、该问题所有正常返回的回答及各自评论和楼中楼 |

第1项需要能确定“当前是哪篇回答”。如果你在纯问题总页，或当前回答数据缺失，会提示不能唯一确定，不会偷偷选择第一篇。此时打开想看的具体回答，再用第1项；第2项可以直接使用。第2项不受页面刚加载的4篇、5篇等预载数量限制。

4. 等待右下角进度变化。可以去做别的工作，但不要刷新、关闭目标标签或在同一标签切换问题；刷新后不能续跑。请求串行进行，启动间隔至少1.5秒，不提供加速或自动重试。
5. 结束后自动发起一次JSON下载。检查浏览器下载列表，确认确实有文件；若没看到，可点“保存本机JSON”。面板提示“已发起下载”只是发起了操作，不能保证浏览器已经写入磁盘。

## 面板状态和小叉是什么意思？

| 状态或操作 | 结果 |
| --- | --- |
| 检索完成、所选范围文字已核齐 | 程序的严格检查通过，自动发起下载；仍不能证明站点没有隐藏或删除内容 |
| 检索结束、仍有缺口 | 已结束，但计数、正文或关系等有未核齐项；保留实际得到的数据并自动发起下载 |
| 提前停止 | 遇到错误或保护限制，结果未完成，保留证据并尝试下载 |
| 菜单上的× | 不开始检索，不下载 |
| 运行中的× | 放弃本次，取消请求及等待，关闭面板，不再自动下载残缺结果 |
| 停止并保存已有数据 | 有意保留部分成果，停止并下载，面板保留 |
| 完成后的× | 只关闭面板，不删除文件，也不重复下载 |

运行前手动保存过的快照不会因×被删除。网络请求一旦发出，服务端已收到的部分无法撤回。面板未收尾时重复点击不会再开一个任务。

## 能采什么、不能采什么？

本工具以文字及正常返回的评论、楼中楼为目标。不下载图片或视频，不播放、不识别、不转写视频；原始HTML中可能保留图片和媒体引用。空正文不能自动判断为视频，仍保留未知提示。

已删除、隐藏、审核中或网站没有返回的内容无法保证得到。页面显示的总数和接口返回数有时不一致；工具保留差额，不通过换账号、绕过权限或无限重试补齐。每次最多1000次请求，设置20分钟预算，单请求最多20秒；浏览器后台暂停可能推迟检查和保存，不保证准点结束。

历史一题的真实单篇结果为27条根评论加22条楼中楼，49条全部核齐；整题取得87/90篇回答、391条评论，其中175条楼中楼，各组回复数及父链核对匹配。没有返回的3篇身份与原因未知。这是0.6.5实测；0.6.6修正未知计数的保守判断，0.6.7补齐公开集成、问题原文与跨页计数检查及楼中楼合成回归，均没有新的实网验收。不能据此承诺任意问题至少97%，也不能承诺所有回复绝不遗漏。

## 隐私、报错与分享

扩展只申请当前标签操作和脚本注入权限，没有Cookie、额外主机或存储权限，不上传结果。运行使用当前页面正常访问能力；遇到登录、权限、风控、网络或格式错误即停，不自动重试。

JSON包含作者名、原始HTML和链接，不是匿名资料。不要把它与源码一起公开，不要直接把原始HTML放进可信页面执行。报错时提供版本、所选范围、最终状态和不含账号隐私的截图；需要JSON证据时先与维护者确认最小范围。不要提供Cookie、请求头或完整网络抓包，不要反复重跑整题。

源码按本仓库的 [MIT许可证](LICENSE) 提供，可免费使用和修改。该许可不授予对第三方知乎内容的权利；仅处理有权访问的内容，并遵守网站规则。工具与知乎官方无隶属关系。

本工具采用有限维护方式，不承诺固定更新频率、问题响应时间或长期兼容所有网页变化；欢迎贡献，也允许暂停维护。源码公开不等于浏览器商店审核通过。

## 资料都放在哪里？

- `extension/`：可直接加载的源码、详细使用边界、维护契约和三套合成测试。
- `研发与维护记录.md`：研发过程、关键取舍、已知缺口和下一步维护事项，供接手AI或开发者阅读。
- `接管验收.md`：维护、发布检查及未来移交要求，本地维护责任与公开发布分别处理。
- `evidence/`：脱敏测试回执及真实验收数字摘要，不含采集原件或网友正文。
- `delivery-manifest.json`：交付文件及SHA256清单；SHA256用于发现文件内容是否变化。
- `verify-delivery.py`：维护者核文件清单和运行离线测试的入口。普通使用者无需运行。

本工具由ChatGPT Workflows项目维护。开发者可在本目录运行 `python -B verify-delivery.py` 核文件完整性及离线测试；普通使用者无需运行。`evidence/` 保留脱敏历史记录，不作为0.6.7当前实网验收。
