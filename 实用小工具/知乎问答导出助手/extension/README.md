# 知乎只读导出 0.6.7：本地试用版

[English](README.en.md)

在知乎问题页或任意回答页点击扩展，先选范围，再导出本机JSON。读取正常返回的回答、评论及楼中楼，没有内置AI总结，不发布、互动或上传资料。0.6.1两项范围已有真实验收；0.6.5已有单篇和整题正常运行实测；0.6.6修正缺失计数被当成0的问题；0.6.7补齐项目集成、菜单及公开说明。当前小叉取消、异常与下载失败主要经离线验证，未上架浏览器商店。

## 安装与选择范围

1. 在Chrome或兼容MV3的浏览器扩展页加载含manifest.json的目录，详见[安装说明](../README.md#怎样安装)。升级时先取得新版文件，再重新加载原扩展并刷新知乎标签；重载不会下载更新。扩展卡片和菜单应同时显示0.6.7；报错或版本不符时先停止并保留截图。
2. 从日常浏览中打开一个问题或一篇回答即可，不必区分问题总页。话题、首页、搜索列表包含多个问题，须先点开其中一项，不自动批量扫描。
3. 点击扩展弹出两项菜单，选择前不发送采集请求，可直接关闭。重复点击不会多开任务。
4. 第1项“检索这个帖子的原文以及当前的这一篇回答”：包含问题原文、当前回答及其下所有正常返回评论和楼中楼。回答页按网址确认当前回答，无需下拉选择。问题总页或当前回答数据缺失时，提示“不能唯一确定”且不发请求；请打开想看的具体回答后使用第1项，或直接选第2项。不猜第一篇，不扫描该作者其他回答。
5. 第2项“检索这个帖子的原文以及所有的回答”：包含问题原文、本问题所有正常返回回答及对应评论和楼中楼，两种页面都能启动。回答页启动时读取同一问题正常总页作为起点，不切换你的页面；失败即停，不绕过限制。整题遍历不受当前页面预载回答数量限制。

选择后面板显示题目、范围与进度。可切去做其他事，但保留目标标签，不刷新、关闭或切换问题；刷新/关闭无持久恢复。菜单打开后若导航到别的问题，选择时也会停止。

## 停止、保存与结果

面板在运行中显示当前进度；结束后明确显示“检索完成：所选范围文字数据已核齐”“检索结束：仍有缺口，未核齐”或“提前停止：结果未完成”，并列出回答数、评论数与耗时。正常结束（含有差额）、错误保护停止或点“停止并保存已有数据”均尝试下载JSON，面板保留。下载提示仅说明“已发起下载”，不代表浏览器已写入文件；没有文件时点“保存本机JSON”。发起下载抛错时显示重试提示，仍保留保存和关闭入口。

菜单点×直接关闭，不请求、不下载。采集中点×表示放弃：取消当前请求及等待，隐藏并最终移除面板，不新增下载。它不会删除此前手动保存的快照。正常结束后的×只关闭，文件保留。需保留部分数据时用“停止并保存已有数据”，不用×。隐藏防重入标记保留至取消收尾，避免重复启动。已发送的服务端请求不能撤回，浏览器暂停或同步解析不能由脚本抢占。

两种正式模式都串行执行，启动间隔至少1.5秒，最多1000请求，设置20分钟总预算。单请求截止取20秒与总剩余时间的较小值，启动页读取一并计入。后台计时器可能延迟，不能保证20分钟整自动保存；恢复后核时限，超预算不报完整。HTTP、网络、格式、超时、归属异常停止，不重试或切换身份。

- 单篇：collectionScope.kind为single_answer_comments，diagnostics.run.mode为single_full，answerId是所选回答。runStatus为single_finished表示单篇遍历结束；selectedAnswerComplete=true表示该篇正文与评论核齐。顶层complete=false仍表示未核齐整题，不等于单篇失败。
- 整题：collectionScope.kind为question，diagnostics.run.mode为question_full。complete=true要求全部严格核账通过；finished_partial表示有缺口；stopped表示提前停止。
- coverage列出实得回答、根评论、回复及未核齐原因。returnedScopeProcessed只表示已处理返回范围，不保证网站未返回内容。
- 未支持结构、正文或计数变化、缺父、折叠计数不一致等保留缺口。结束重读来自页面初始数据，不是实时服务端查询。

异常时保留最终JSON与不含账号隐私的面板截图，不反复重跑，不提供Cookie、请求头或HAR。JSON含作者名、原始HTML及链接，不是匿名资料，不应与源码一起公开。图片仅保留引用，不下载图片字节或视频，不执行导出HTML。

## 文字与媒体范围

不下载、播放、识别或转写视频。视频中的字幕或语音不算已采文字；原始HTML可能保留媒体引用，但不会执行它们。正常返回的评论和楼中楼文字照常采集。图片仍只保留引用，不核图片字节。

空正文标为empty_unknown，不能自动当作视频通过；只有人工或可验证来源确认后，才能解释为视频范围排除。人工结论不改写旧JSON，不硬编码网友回答ID。

0.6.2保留两版原始HTML，只将已知知乎图片域名及8位十六进制source参数变化归为image_url_representation，不再仅因此报正文缺口。文字、图片路径、其他参数、未知域名或结构变化仍保留缺口。它不证明两条链接下载的图片字节相同，也不放宽回答数、评论数或父链判断。

## 权限与开发验证

仅使用activeTab、scripting，无新增主机、Cookie、存储或后台上传权限。停用或移除后刷新已注入标签，下载文件保留。回退时保存结果，加载旧源码副本并刷新。

普通使用不需要Node；开发者可运行纯合成离线测试：

```powershell
node test-portable.cjs
node test-menu.cjs
node test-text-scope.cjs
```

三条命令应输出result=PASS。也可在上级目录运行 `python -B verify-delivery.py`，同时检查清单、版本、权限与语法。测试无网络，不读账号或真实采集资料，不替代现场验收。源码哈希见[交付清单](../delivery-manifest.json)；维护边界见[MAINTENANCE.md](MAINTENANCE.md)。

0.5.0曾在一个问题完成真实整题返回范围遍历，声明计数仍有差额；0.5.1修补后通过独立审查。0.6.1在另一问题完成单篇及整题范围实测：单篇49评论核齐，整题87/90篇、391评论，仍有声明差额。0.6.5同题复测为单篇49评论（22条楼中楼）核齐、整题87/90篇（96.67%）、391评论（175条楼中楼），返回的评论总数、各组回复数量与父链匹配。三个未返回回答的身份和原因未知，不能保证已删除、受限或未返回内容。整体覆盖率是单题实测，不承诺其他问题至少97%；这些历史结果不代签0.6.7实网或跨浏览器验收。


## 适用标准与试用限制

单篇重点核对评论接口总数、每组楼中楼数量、父链和分页；只对正常可见且返回的数据提供核验，不能恢复隐藏或已删回复。整题以尽可能覆盖大部分回答为实用目标，允许少量未返回项；约97%是操作者的容忍示例，不是代码保证或硬阈值。媒体不在本次验收要求内，原HTML及图片引用仍保留，不下载图片或视频。

完整性complete字段继续严格判定，不因放宽实用目标改为true。“部分数据”不等于任务崩溃，应结合coverage看是否已遍历和具体差额。当前样本三篇列表/评论接口计数不一致但评论接口总数均匹配，保留告警；两篇空正文已被操作者人工核验为视频，不自动泛化为空正文通过。

分享时只提供源码ZIP和通用说明，勿附采集JSON、截图或私密维护记录。源码包可在解压后加载本地扩展；它是需手动安装的试用工具，并非浏览器商店审核版，也没有跨浏览器或任意题目全量保证。不要将原始HTML直接注入可信网页执行。

0.6.6起保留缺失的折叠/审核计数为未知，并标注不能确认完整，不再默认0。此修正不增加请求，不影响已明确返回零值的历史样本。源码使用[MIT许可证](../LICENSE)，第三方内容不属于本工具可授予的权利。当前为有限维护的本地工具，不承诺固定支持或更新周期，不承诺任意问题都达到固定覆盖率。
