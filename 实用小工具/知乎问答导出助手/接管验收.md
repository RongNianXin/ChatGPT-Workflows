# 维护与发布验收

本文件只规定知乎只读导出工具的便携验收。当前应用0.6.7、源码采用MIT许可；维护责任属于ChatGPT Workflows，不转移其他项目的业务、身份或授权。

## 维护者操作

1. 读取README、研发记录、extension/MAINTENANCE及历史evidence的适用范围；需要传输ZIP时另核发送方提供的包摘要。
2. 使用完整、独立的源码副本，保留当前目录结构，不覆盖来源不明的修改。
3. 在本目录运行 `python -B verify-delivery.py`。需要已有Python和Node，无网络、无安装；检查固定文件集合、哈希、版本、权限、语法及63项纯合成测试。缺运行时只暂停相应检查，不自动安装。
4. 修改后同步应用版本、说明和文件清单，核中英README的源摘要及必要回归；历史evidence不改写成当前测试回执。
5. 在已有维护记录保存实际版本、清单/源码摘要、检查结果及未验证项。文件存在或命令启动不等于检查通过。

源码、普通说明、合成测试及脱敏历史证据可以随仓库分发。原始采集JSON、账号截图、私密fixture、机器路径、日志和来源聊天不进入公开候选。MIT许可只覆盖有权许可的源码与资料，不授予第三方网站内容权利。

完成必要审查及精确暂存后，按仓库验收入口检查实际提交候选；远端发布、商店上架、公开答疑或回复分别核对当前授权。只提交经审查的确切文件，不夹带其他工作项。
