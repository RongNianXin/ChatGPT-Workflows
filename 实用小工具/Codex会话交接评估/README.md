# Codex 会话交接评估

[English](README.en.md)

保存常用任务 ID，一键查看本机 Codex 会话的回合、文件大小、上下文压缩及交接参考信息。**当前推荐下载版本：Windows 工作台 0.2.0-dev.10。** 无需输入命令；源会话只读，数据不上传。

当前仓库源码包含列表空值与中文编码修复；已发布 dev.10 ZIP 尚未更新。页面修复刷新网页即可采用；后台脚本与分析器修改需仅重开本工具，无需退出或重启 Codex。

## 下载与启动

1. [下载 Windows 独立工具 ZIP](https://github.com/RongNianXin/ChatGPT-Workflows/releases/download/windows-sessiondesk-v0.2.0-dev.10/Windows-SessionDesk-0.2.0-dev.10.zip)，完整解压，双击根目录 `Start-SessionDesk.cmd`。无需克隆整个仓库；不要单独打开 HTML。
2. 已克隆仓库的用户，双击 [Start-SessionDesk.cmd](Start-SessionDesk.cmd)。仓库源码可能先于下载包，实际版本以页面顶部显示为准。
3. 保存任务 ID，单项“查询/刷新”只更新该任务；“一键刷新”更新完整列表。名称与本地项目自动读取。右侧基本报告与详细报告分区显示，可切换简体中文或 English。

使用 Windows 自带 PowerShell 5.1 和浏览器；当前验证 Windows Edge，macOS 与其他浏览器未验证。本版本仍为开发预览，不宣称已经完成所有设备兼容性或超大日志验证。

`windows-local` 是正式程序内部目录，不是临时文件；日常只需运行本目录的启动 CMD。个人任务与历史保存在其 `.local` 中，不随仓库分发。

## 版本状态与下载核对

`0.2.0-dev.10` 已在 GitHub 提供下载，但仍标记为开发预览，不是正式稳定版。仓库源码、已发布 ZIP 和本机临时打包文件可能处于不同时间点；文件名相同也不能证明内容相同。遇到“本地能用但远端是否同步”这类问题，应分别记录：本地运行包版本、远端 Release 标签、下载 ZIP 的 SHA-256，以及是否为预发布。

下载后可在 PowerShell 中运行下面的命令核对实际文件：

```powershell
Get-FileHash .\Windows-SessionDesk-0.2.0-dev.10.zip -Algorithm SHA256
```

再把结果与 Release 附带的 `SHA256SUMS.txt` 对照。校验值不同表示两份文件不是同一个字节级归档，不能仅凭版本号判断已同步；如要正式发布或替换远端附件，应重新完成精确包验收并单独确认远端动作。

## 日常操作

- 常用任务没有固定条数上限，已回归 20 条；支持搜索、上下移动和“一键排序”，顺序保存在磁盘。“一键刷新”最多同时查询两个任务，完成后保留原选中项；原先没有选中项时右侧继续为空。
- 最新成功结果按下方评分规则显示交接等级；标记来自查询快照，旧分数明确标为历史规则。
- 每个任务、每种语言保留最近一次成功查询的基本输出和详细报告。重开显示原查询时间及“历史快照”提示，只有主动查询才更新统计。
- **仅关闭网页不会关闭后台服务。** 不再使用时点击页面顶部的“退出工具”，停止本工具服务及未完成查询，不影响 Codex 对话任务。按钮提供中英文悬停说明；退出后可以关闭页面，下次双击启动入口恢复清单与已保存结果。
- 中断或失败的刷新不会把旧历史改成新成功；此前保存的历史仍可在重开时查看。查看结果不代表 AI 当前仍在运行。

## 评分与滑条

当前结果采用 `handoff-score-v6-traditional`，恢复传统“文件大小分＋压缩次数分”。保留0～10分、3分橙色建议交接、8分红色必须交接、十格条和3/8刻线；未查询或无合法分数时为空灰格，不冒充0分。

| 子分 | 0分 | 1分 | 2分 | 3分 | 4分 | 5分 |
| --- | --- | --- | --- | --- | --- | --- |
| 文件大小（MiB） | <30 | 30～<50 | 50～<100 | 100～<200 | 200～<400 | ≥400 |
| 上下文压缩次数 | <4 | 4～<7 | 7～<10 | 10～<15 | 15～<20 | ≥20 |

总分是两项相加：例如46 MiB、10次压缩，得到1＋3＝4分；200 MiB、15次压缩，得到4＋4＝8分。文件大小使用已发现会话分段的聚合字节数÷1,048,576；压缩次数使用已识别压缩事件数。报告列出本次两项实值、贡献、完整分档和总分算式。

当前输入量、窗口占比和实测增长均不参与评分。工具不预测未来压力或到达某个观察目标的回合数。85%/95%仅作独立容量提醒。旧动态评分保留并明确标为历史，重新查询后才得到传统新分数；无合法分数的旧比例不转成分数。

传统阈值是经验规则，尚未通过全程成本与完成质量校准；文件大小不等于当前输入Token，压缩次数不等于当前负担。不能宣称3分就是最省Token点，也没有可靠依据把100,000或150,000 Token作为统一必须交接线。

卡片在评分下方直接展示日志中的最近一次请求输入Token，不重复展示计分方法；详细报告保留完整依据。恢复历史、来源变化或刷新失败保留旧结果时，可见标为“上次查询输入”，悬停可看原观测时间和查询时间。

原生单请求输入独立取数：合法非负安全整数（含0）可在窗口或累计计数缺失时展示，不用累计输入或用户消息字数替代。容量、占比及增长率另行验证。`input_tokens`已含`cached_input_tokens`，不再相加；窗口取同一事件的`model_context_window`，不是路由组最大窗口；累计`total_tokens`缺失时不建立连续观测。趋势用同会话、同模型、同声明提供商、同窗口与同压缩段最近六个已完成回合的末次观测，计算五个间隔的平均值；缺失、非法用量为未知，合法零为零。压缩、模型/提供商/窗口切换、累计计数回退或缺新用量时重建基线，重复快照不增样本；负增长保留，样本不足时增长率未知；不设任意观察目标或预测到达回合。声明提供商不能证明实际网关上游。

交接决策另过两道检查：当前工作单元是否完成、证据是否齐全且能否在新窗口恢复；后续节省是否足以抵消交接整理、规则重读、缓存重建和预期返工。日志中的回合结束不能代替业务完成；本工具不能可靠自动判断，报告明确为未知。容量足够时优先做完当前工作单元，在安全断点交接；容量不足时先保存证据和可恢复断点，不中断在途操作，也不为等整项完成而冒险继续。8分以上是传统经验评分的红色提示，不是立即切窗命令。

简化的Token回本条件是 `N × (C - R) > H`：旧窗口每次模型请求输入为C，新窗口重建后为R，交接额外开销为H，后续模型请求数为N。它需要同口径且未来输入近似不变；一轮用户对话可能有多次模型请求。缓存比例、输入/输出单价、长上下文倍率、时间成本和质量风险都可能改变结论，不能将Token差额直接等同于金额。输入不全时不输出伪精确收益，不要求操作者为此额外采样，不自动执行交接。结果保留查询时间，不能证明任务正在运行或已经完成。

## 升级与旧版本

升级前退出旧工具，备份其 `windows-local/.local`，再复制到新目录对应位置；不要覆盖另一份已有数据。目录内含任务清单、历史与报告，删除程序目录前必须保留该目录。dev.5 及更早版本不能复原从未保存的基本输出；完整历史保存从 dev.6 成功查询开始。

旧 HTML 原型和虚构演示已退出正式交付入口，其阶段代码可从 Git 历史检索。本页只推荐当前 Windows 版本；命令行分析器继续保留，供脚本调用与独立核对，不是另一套统计算法。

## 统计与隐私边界

本工具给出工程参考，不承诺官方阈值或实时状态。多分段 Token 基线、截断输入、持续写入的日志和缺失计数可能影响完整性；结果是读取快照，不是冻结的实时总账。名称和项目依赖 Codex 当前本地记录格式，格式变化时可能需要适配。

详细报告和历史可能包含完整用户输入及本地路径，只保存在 `.local`，不得未经审阅直接公开。ZIP 不包含这些私有文件。仅监听本机回环地址并校验随机连接凭证；退出不会关闭其他程序或 Codex 任务。所有版本都应保留原分析器的完整性提醒，不能把缺失 Token 当作零。
