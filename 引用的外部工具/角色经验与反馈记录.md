# 角色经验与反馈记录（AI 内部记录）

本文件只保存已经去重、核验并适合跨项目复用的经验。单个项目的原始聊天、私密材料、未核验结论和完整第三方角色正文不写入这里。

## 记录格式

每条经验由中央总指挥整理为：

- 工具编号 / 角色：
- 来源、版本或哈希：
- 适用项目类型或任务：
- 观察到的问题或新增价值：
- 证据位置：
- 建议动作：保留 / 调整说明 / 更新角色 / 新增角色候选 / 暂停使用
- 验证结果：
- 影响范围：
- 失效条件：
- 状态：`PROPOSED / VERIFIED / APPLIED / REJECTED / UNKNOWN`

## 自动反馈流程

1. 项目总指挥从自然语言中识别这是使用反馈、角色优化建议还是新增角色需求。
2. 它只读取判断该反馈所需的最小材料，生成结构化建议包，不直接改共享角色或中央状态。
3. 中央总指挥按来源、版本、角色和问题去重，核对证据后更新共享状态、工具 README 或安装记录。
4. 没有证据的意见保留为 `PROPOSED` 或 `UNKNOWN`，不直接改变角色文件。
5. 更新后回读共享状态和受影响项目入口；项目总指挥下次调用时自动看到最新状态。

操作者始终只需要对当前项目总指挥说自然语言，例如：“这个角色对微信小程序表单检查帮助不大，建议增加异常状态检查。”
