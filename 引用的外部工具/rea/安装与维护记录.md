## 安装与副作用

登记不安装包，也不改用户配置。未来若获授权准备，先定点检查已有实物、版本、路径和项目范围；来源可访问或有安装说明不构成执行许可。

`npx ... setup --dry-run` 只是不应用 REA 配置事务，npx 仍可能下载、缓存并执行软件包。正式 setup 会改所选客户端配置，并默认安装其配套 Skill；安装范围、备份和回滚须先核。Windows setup 不替用户安装 Ghidra 或 JDK；不能把一个 npm 命令描述成全部环境已就绪。

原生静态分析可启动 JVM 并写私有导入工程、缓存或快照，不等于运行目标，也不是整个进程零写入。隔离目录和进程管理不是安全沙箱。首次导入、输出大小、模型上下文和清理成本纳入同一任务预算；超时后不要假定引擎已退出。日志、原始代码和捕获数据按项目隐私规则保存，不公开本地原件。

回滚安装或配置仅在授权且当前文件仍匹配预期时恢复该次变更；不能删除其他工具或他人配置。登记回滚只撤回本次文档增量，保留既有成果。工具退役保留编号和历史，不复用 `EXT-004`。
