# 外部工具通讯录

<a id="外部工具目录"></a>

这是给人和 AI 共用的工具黄页，也是外部工具唯一的编号与入口索引。先按“用途标签”和“适用场景 / 基本用法”找候选，再读选中工具的详细说明，不必逐个翻阅所有工具。文件路径沿用 `外部工具目录.md`，避免旧链接失效；不另建第二份名单。

入口识别名：“外部工具”“工具通讯录”“外部工具通讯录”“外部工具目录”均指向本通讯录，不指定某个具体工具。操作者不必记完整名称；完全不提工具名时，已启用并实际加载新版规则的 AI 仍按[默认选择门禁](外部工具自动对接规范.md#tool-default-routing)判断是否需要外部增强，不等待提醒。

## AI 的最短读取路径

从已核验规则根定位本通讯录 → 按目标、阶段、名称或别名筛选 → 只读选中工具的 README → 本次确需调用时再读指南、维护记录与必要配置。同阶段复用有效选择，简单任务基础能力足够时直接完成；普通按需选择不缩小正式规则刷新或交接的必要读取范围。

工具详细提示词、命令、输入参数、环境配置和故障处理只维护在各自子目录；共同发现、权限及跨项目验收只维护在[统一自动对接规范](外部工具自动对接规范.md)。本通讯录不复制这些正文，也不承诺真实窗口已自动采用或已节省 Token。

## 随用随取，不预装工具库

登记时只保留最小用途、正式来源、状态和指针，不默认完整克隆、下载或预加载。真正需要时，在已有有效授权范围内取得版本明确的最小可运行资源；依赖要求完整包时不能用残缺文件冒充可用。优先复用已验证实物，长期需要后再补子目录中的使用经验。

工具子目录保存可分发说明，软件实物与之分离。仓库内实物须已忽略且未跟踪；仓库外另核精确目标路径写入许可，不受本仓库 `.gitignore` 管理。下载包、依赖、缓存和私有输出均不得混入公开交付，不自动清理或删除已有成果。下载主要消耗网络和磁盘，Token 成本取决于实际读取、分析与输出，不能混为一谈。

## 状态含义

- `DOCUMENTED_ONLY`：已经登记说明，但没有证明已安装或可调用。
- `NOT_INSTALLED`：当前没有执行安装，不能把工具链接当成可用工具。
- `READY_FOR_ACTIVATION`：共享文件、来源、版本和安装范围已核验；本项目基线、授权及任务绑定通过后，才可以按激活卡使用。
- `UNKNOWN`：关键证据缺失或冲突，暂停依赖该工具的动作。
- `RETIRED`：不再推荐新任务使用，但保留历史记录。

## 新工具登记最小要求

复制 [`外部工具接入模板.md`](外部工具接入模板.md)，为工具分配下一个未使用的 `EXT-xxx` 编号，并在正文目录中至少提供：

1. 人话用途和适用阶段；
2. 来源、版本和安装范围；
3. 调用提示词或操作步骤；
4. 权限、数据、Goal 和回滚边界；
5. 结果格式、验证方式和停止条件；
6. 维护记录与当前状态；
7. 名称、别名、正式来源和唯一入口的定位证据，以及新窗口仅凭规则根与任务目标的跨项目验收记录。

登记本身不产生安装、调用、跨任务通信、产品修改或远端写入授权。
