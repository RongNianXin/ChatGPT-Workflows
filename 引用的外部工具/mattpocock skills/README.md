## 先这样使用

不需要记命令或角色名。在已加载本入口的对话中直接说目标，并说明先讨论还是实际实施。其他新对话可补一句“请使用Matt Pocock技能库”；AI负责核对实际文件和适用方法。

第一次推荐用一个只读练习：

```text
请使用Matt Pocock技能库的wait-what，解释一下“回归测试”是什么，结合个人开发举一个例子。用中文，先简短说明，最后给一个小操作建议。只解释，不修改文件或设置。
```

成功时应得到中文解释和具体例子，不应生成项目、改代码或发布内容。如果提示技能找不到，直接回复“请检查Matt Pocock Skills是否已被当前对话发现”，让AI核验；不要自行重复安装。

有一个想做的功能但说不清时：

```text
请使用Matt Pocock技能库帮我澄清下面的想法。先只讨论，不修改文件。你先判断我已经说清了什么，再一次问一个真正影响设计的问题，并给推荐方案和理由。我的想法是：【写下想做的功能】。
```

需要实际开发时，说明功能、输入、期望效果和允许修改的项目即可。AI先核对工程技能的项目初始化及现有版本兼容性，再按需选择实现、测试或审查方法；已经明确的信息不重复问。不要求操作者把全部技能串成固定流水线。
