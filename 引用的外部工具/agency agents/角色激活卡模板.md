- 本轮模式：`只读审查 / 允许修改指定本地文件 / 其他（说明）`

## 输出契约

补充审查按下面顺序输出；规划或已授权实现按主任务交付格式输出成果、变更理由及验证证据，并保留成本、未验证项和停止/下一步，不强制把实现成果写成审查发现：

1. 基线中已经存在的内容；
2. 新增且有证据的发现；
3. 每条发现对应的证据位置；
4. 最小验证办法；
5. 额外时间、额度或资源消耗；
6. 未验证项、阻断和停止建议。

## 预算与停止条件

- 最多调用轮次：
- 开始前消费与回读：`attempts_consumed`、调用状态、输入基线、原开始时间、恢复锚点；持久回读成功才执行，未完成/失败也占一次。
- 已用轮次、同问题累计尝试、已消耗成本及剩余额度：恢复不清零
- 时间 / Token / 额度上限：
- 到达什么情况立即停止：没有新增可核验价值、输入不足、越过权限、状态冲突、预算用尽或发现无法安全验证的风险。
- 角色结果是否可以改变原 Goal：不能自动改变；由项目总指挥按主工作流重新决策。
- 续接与自动调用：按共同规范第5.1/5.2节恢复同次、原开始时间与累计预算，不因角色/阶段/批次/窗口变化新领次数。未完且可安全续写才继续，无法安全续写则收口；完成部分不重跑。角色缺口只停依赖调用，主任务停止规则不被覆盖。
- 交接载荷：绑定锚点、职责集合、阶段、未完调用、累计预算及撤销状态；新实例独立读正文核权，不复制全文或新建平行账本；专项实际加载确认另记。
- 角色切换/撤销/失效：目标或角色版本/权限变化时定点重核；明确停止时撤销，不因旧卡存在而复活
