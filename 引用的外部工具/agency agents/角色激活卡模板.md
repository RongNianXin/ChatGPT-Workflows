# Agency Agents 角色激活卡模板

每次试用一个角色前复制一份填写。空白字段不要猜，写“待确认”。

## 基本信息

- 状态：`PROPOSED / ACTIVE / COMPLETED / SKIPPED / REJECTED`
- 角色名称与 slug：
- 角色来源：`https://github.com/msitarzewski/agency-agents`
- 来源版本 / 提交 / 文件哈希：
- 安装范围：`NOT_INSTALLED / project-scoped / user-scoped / other`
- 负责的中央总指挥：
- 负责的项目总指挥：
- 试用任务与当前精确断点：

## 目标与输入

- 本轮要回答的一个问题：
- 角色为什么适合这个问题：
- 已保存的基线位置：
- 允许读取的材料：
- 不允许读取的材料：

## 权限边界

- 本轮模式：`只读审查 / 允许修改指定本地文件 / 其他（说明）`
- 允许写入的精确路径：
- 禁止动作：自动安装、加载其他角色、修改未列出的文件、联系其他任务、远端写入、部署、替代人工试玩或宣布未验证结果。
- 是否需要操作者另行确认：

## 输出契约

角色必须按下面顺序输出：

1. 基线中已经存在的内容；
2. 新增且有证据的发现；
3. 每条发现对应的证据位置；
4. 最小验证办法；
5. 额外时间、额度或资源消耗；
6. 未验证项、阻断和停止建议。

## 预算与停止条件

- 最多调用轮次：
- 时间 / Token / 额度上限：
- 到达什么情况立即停止：没有新增可核验价值、输入不足、越过权限、状态冲突、预算用尽或发现无法安全验证的风险。
- 角色结果是否可以改变原 Goal：不能自动改变；由项目总指挥按主工作流重新决策。

- 最终决定：`继续原 Goal / 安排验证 / 停止角色试验 / BLOCKED`
