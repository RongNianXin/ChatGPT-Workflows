# 发给其他项目总指挥的提示词

下面这段可以直接复制。把方括号中的内容换成你的项目名称和当前目标；如果暂时不知道，就保留“待确认”，让对方先核验。

```text
我们中央工作流已经登记了一个外部角色提示词库 Agency Agents：
https://github.com/msitarzewski/agency-agents

请先把它当作“可选的专业审查工具”，不要自动安装、加载全部角色，也不要因为这条消息改变当前 Goal、权限、单写者或停止条件。

请先阅读本项目的 Agency Agents README，并由 AI 按需读取调用指南、角色激活卡、安装记录和共享角色状态；操作者不需要手工拼接这些提示词。

当前项目：[项目名称]
当前目标：[目标或待确认]
我想让你判断：Agency Agents 是否能对这个目标提供可核验的额外价值，以及最适合的一个角色是什么。

请按以下顺序处理：
1. 先确认当前任务状态、基线、权限和停止条件；如果状态不清楚，先报告 UNKNOWN/BLOCKED。
2. 先读取共享角色状态；如果已有相同来源、版本、哈希和共享路径，直接复用，不重复安装。
3. 只推荐一个最小角色，并说明选择依据、来源版本、输入材料、输出格式、预算和停止条件。
4. 先形成或读取项目基线，再生成绑定本专项任务的激活卡，进行最多一轮只读角色审查。
5. 角色不得自动安装 Agent、修改产品、联系其他任务或执行远端写入；如需安装，只返回项目范围安装候选给中央总指挥。
6. 输出必须区分：基线已有内容、带证据的新发现、最小验证办法、额外时间/额度成本、未验证项和是否继续。

如果角色尚未安装，请明确写 NOT_INSTALLED，不要把“知道这个 GitHub 地址”写成已经接入。发现角色问题、建议优化或缺少角色时，把自然语言转成结构化反馈包交给中央总指挥，不要求操作者另找反馈窗口。
```

## 什么时候发这段

- 你要让某个项目总指挥知道有 Agency Agents，并请它判断是否值得用时，发送整段。
- 你已经知道具体角色和目标时，仍保留“先核验状态、版本和权限”的部分。
- 你只想问概念问题时，可以只发仓库地址和“请阅读调用指南并解释”，不必启动角色审查。

## 发出后你应该看到什么

项目总指挥应返回角色建议或明确的 `NOT_INSTALLED`、`UNKNOWN`、`BLOCKED`，并说明证据和下一步。它不应直接把这段消息当成安装授权、产品修改授权或远端写入授权。
