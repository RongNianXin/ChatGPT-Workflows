## 维护规则

普通对话持续适配已补充到唯一README、调用指南第5节及激活卡：项目约定和业务绑定分层，实际角色选择、加载、恢复和质量分别取证。本次只改工作流文档，未安装/更新角色或修改全局配置，未执行真实跨阶段/跨窗试用；安装状态和原限定试验预算保持原记录。

1. 本仓库唯一维护者负责公共登记；共享库维护者负责安装、更新、来源核验和回滚记录，执行前须有覆盖目标目录和动作的授权。项目总指挥负责项目适配与本地激活，不直接改中央登记。
2. 需要安装或升级时，先记录目标角色、范围、版本、预期文件和回滚办法，再执行对应的本地安装操作。
3. 项目总指挥只能选择已登记且版本可核验的角色；不能因为收到一个 GitHub 链接就认定已经接入。
4. 每次角色试用都要有一张激活卡和一份结果收口记录。
5. 发现角色来源变化、安装目录变化、权限变化或工具行为不确定时，状态改为 `UNKNOWN`，暂停依赖该角色的动作。
6. 删除或升级角色前保留旧版本指针和影响范围；不要在项目任务中静默替换角色正文。
