# Agency Agents 安装与维护记录

这份文件是中央工作流判断“是否已经接入”的单一记录。没有证据的状态不得写成已安装。

## 当前登记

- 名称：Agency Agents
- 来源：<https://github.com/msitarzewski/agency-agents>
- 用途：按一个受限的专业角色对已有基线进行补充审查
- 当前仓库状态：`DOCUMENTED_ONLY`
- 当前安装状态：`NOT_INSTALLED`
- 当前激活角色：`NONE`
- 安装范围：`NONE`
- 当前版本 / 提交 / 文件哈希：`待安装或核验`
- 最近一次只读核验：`2026-10-03`，已核对公开仓库用途和 Codex 转换/安装路径；未执行安装，未声明角色可用
- 记录负责人：当前项目总指挥

## 维护规则

1. 中央总指挥负责安装、更新、来源核验和回滚记录。
2. 需要安装或升级时，先记录目标角色、范围、版本、预期文件和回滚办法，再执行对应的本地安装操作。
3. 项目总指挥只能选择已登记且版本可核验的角色；不能因为收到一个 GitHub 链接就认定已经接入。
4. 每次角色试用都要有一张激活卡和一份结果收口记录。
5. 发现角色来源变化、安装目录变化、权限变化或工具行为不确定时，状态改为 `UNKNOWN`，暂停依赖该角色的动作。
6. 删除或升级角色前保留旧版本指针和影响范围；不要在项目任务中静默替换角色正文。

## 计划中的首轮试用

- 候选项目：示例游戏项目
- 候选角色：Game Designer
- 前置条件：项目 Goal 从正确断点恢复、基线已保存、角色来源和版本可核验
- 推荐模式：最多一轮只读审查
- 当前状态：`NOT_STARTED`

## 明确不做

- 不在本记录里保存完整第三方角色正文。
- 不自动把角色加载到所有项目。
- 不把角色审查结果当成试玩、测试、部署或产品改动完成证明。
- 不因本记录存在而获得跨任务通信、远端写入或修改其他项目的权限。
