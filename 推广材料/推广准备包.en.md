## Main case: state validation and handoff for a long task

### 60–90 second demo script

1. **Entry (0–10s):** Open the repository README. State that this is an independent community experiment, not an official OpenAI product or endorsement.
2. **Registration (10–25s):** Open the second-generation commander workflow manual and show that the operator registers the rule directory before reading only the rules required by the goal.
3. **Validation (25–45s):** Run a read-only status check covering the current goal, worktree changes, evidence, and authorization boundaries. Mark anything unverified as pending confirmation.
4. **Checkpoint (45–65s):** Show how a handoff snapshot records the exact breakpoint, next action, authorization, and invalidation conditions without treating chat history or old authorization as new authorization.
5. **Resume (65–80s):** In a new window, reread the lightweight configuration and rule fingerprints before continuing from the checkpoint. Explain that rule changes trigger rereading.
6. **Limits (80–90s):** State that tools and reproduced environments are Windows-first, and `Windows Session Desk 0.2.0-dev.10` is a development preview rather than a final release.
