# 总指挥工作流相关文档定位索引

本索引把操作者口中的“相关文档”转换为稳定的文档类别和入口。操作者不需要知道文件名或路径；总指挥按结论性质定位，并在回执中报告实际写入位置。

## 定位规则

1. 先判断本轮结论属于规则、变更履历、当前计划、故障案例、项目状态或交接材料中的哪一类。
2. 同一结论只选择一个主记录位置；其他文件只保留短指针、版本或证据链接，不复制整段聊天。
3. 当前项目已有受控记录时优先更新原记录，不因操作者说“相关文档”而新建同义文件。
4. 规则仓库的规范、模板和工具只能由登记的唯一维护者写入；无写权时形成建议包，不声称已经记录。
5. 写入后必须回读主记录，报告实际路径、事项状态、断点、下一步和证据入口。写入失败时登记 `NOT_RECORDED` 或 `BLOCKED` 及恢复条件。

## 主记录映射

| 操作者想保存的内容 | 主记录位置 | 说明 |
| --- | --- | --- |
| 工作流规则、角色、权限、阶段或停止条件 | 对应的 `总指挥工作流/第二代总指挥的工作模式/*.md` | 只改最贴合主题的规范文件，并同步变更日志 |
| 工作流修改原因、复盘结论、通用经验 | `总指挥工作流/第二代总指挥的工作模式/06-复盘与优化规则.md` | 先判断是否跨项目可复用；项目特有内容留在项目记录 |
| 规则版本、已执行修改和验证结果 | `CHANGELOG.md` | 区分已讨论、计划、已执行、已验证和未验证 |
| 当前长任务的目标、阶段、断点和下一步 | 当前活动计划目录的 `task_plan.md`、`progress.md`、`findings.md` | 由活动计划指针定位，不另建第二套计划 |
| 当前项目总指挥状态、唯一写者和当前任务 | 目标项目已有的 `AI状态索引.md`、中央入口或其注册表 | 必须遵守目标项目自身的控制面规则 |
| 故障根因、复现、修复和恢复条件 | 目标项目已有故障记录；可复用时进入 `故障排查与解决经验/` | 不复制聊天原文，不把猜测写成根因 |
| 总指挥交接、候选、送达和切换 | 目标项目中央交接记录及 `04/07` 指定的交接材料 | 交接附件、回执和 CURRENT 指针必须使用同一事实截点 |
| 广播、规则刷新和接收回执 | `01-操作者操作手册.md`、`09-自动化授权与风险分级.md`、`10-自动状态索引规范.md` 及实际接收方记录 | 规则入口负责模板，接收方记录负责本次事实 |

```text
记录类型：规则结论 / 复盘 / 计划 / 故障 / 项目状态 / 交接
事实或结论：
本轮决定：
当前状态：已记录 / 待核验 / NOT_RECORDED / BLOCKED
下一行动方：
证据入口：
失效条件：
```

本索引只负责定位，不替代各主记录的详细规则，也不产生修改、通信、交接或远端写入授权。
