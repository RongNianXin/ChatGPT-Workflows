# 总指挥交接记录模板

> **当前入口**：操作者手册中的正式交接为 1C/1D；无正式交接的中断恢复为 1G。文中旧 6/6A/6B 只用于历史兼容，不得按场景六资料查阅理解。

涉及程序成果时引用 [04 成果契约](04-状态、目标变更与交接规范.md#成果连续性与运行复现契约)，实例增加以下紧凑字段（不复制完整清单）：交接情境（同机同 worktree / 新 worktree / 跨机 / 合并后）；运行成果、验证证据、现场连续性清单指针；规范化/序列化版本；聚合依据（已复算 / 清单推定 / 旧记录）；Git、增量、依赖构建、运行身份、输入验收各层状态及证据；成果包生成/送达/恢复状态；受影响动作与失效条件。不适用或未验证必须明确，字段由 AI 填写。

本模板属于抽象层，所有字段由旧总指挥自动读取或生成，不是人工表单。它只用于场景 1C/1D 和确认原窗口为总指挥后的 1G 中央交接分支；普通任务与专项任务的中断恢复不使用本模板，也不产生总指挥世代。旧 6/6A/6B 仅为兼容别名。真正使用时，在具体项目管理目录生成实例记录；持久化与逻辑 ID 按索引规范执行，不把项目实例数据写回本目录。便携实例只保留聚合事实和证据指针，轻量加载与展开条件以 `总指挥轻量交接启动配置.md` 为准。

核心必填：身份/世代与单写者、事实截点、目标、中央工作项清单指针及逐项非终态、优先级、精确断点、当前允许/禁止及旧授权不继承、配置/来源指纹、工作区及必要未提交成果、实际验证/未验证、阻断/恢复/失效条件和下一行动方。交接结果另分 `control_handoff_confidence`、`switch_status`、`runtime_acceptance_status`、`professional_acceptance_status`；运行或专业未知只限制依赖动作，不代签控制面。实例必须引用私有不可变封条链的 schema、世代、序号、前序摘要、事件 ID、来源摘要和回读状态；模板不产生第二事实源。下方其他段落按实际用途选择，必要未知必须列出；无 GitHub、运行服务或人工轮次时不生成整段空账。核心事实重复出现时保留一个主值，其余引用；详细证据只给稳定指针。模板不替代 04 的回源核验，预算沿原工作包累计。

## 新总指挥第一次只读动作

操作者可直接使用 `01-操作者操作手册.md` 的“场景 1D：新总指挥接手身份”启动本节。模板只保存项目事实和第一次只读动作，不在此复制操作者提示词，以免两处规则漂移。

1. 完整读取 `总指挥轻量交接启动配置.md`，建立本任务加载记录并比对配置及来源规则指纹；异常项按配置展开。
2. 按“快照 → 项目入口 → 当前进度视图当前区 → AI 状态索引当前指针 → 唯一活跃任务当前阶段”的最小链读取。
3. 用聚合计数、Head、指纹和 PASS/WARN/FAIL 核对当前 Git/GitHub 基线、单写者和任务断点；只有异常项才展开。
4. 只刷新截点后变化、未闭环、派生交付物和交接记录中标记为“受影响/待确认”的对象。人工核验优先读取当前轮次清单和上一轮结案摘要；上一关闭轮次原图默认不读取。
5. 若快照或游标不可靠，先扩大受影响部分核账；仍无法恢复时才退回全量。候选阶段不启动任何推进。
6. 候选报告可切换后，先确认旧封条 live source 仍为 PASS 并生成唯一轮换意图，再等待操作者停止或归档旧总指挥并发送最终确认；确认后做最小失效复核，原子更新 current，消费意图生成新世代 `TAKEOVER_COMPLETED` 封条并回读。授权有效性按新任务重新核验。

旧任务不可读或不可写，或新窗口没有正式交接且不了解项目进度时，不要求旧总指挥完成主动交接。新总指挥改按“入口 → 项目恢复热快照 → 状态索引 → 当前 Git/平台事实 → 受影响冷证据”恢复；先核对已完成凭证和执行中断点，禁止从第一步重跑整个队列。恢复可靠后写入新控制面世代；事实或修改归属仍冲突时保持只读并列出最小缺口。

通过净收益门禁的例外专项或临时 AI 未取得总指挥调度权时不得直接修改中央状态；可以更新便携快照副本。结束时直接向总指挥返回：更新后的快照、实际完成、代码/远端变化及回执、验证、未完成项、阻断、下一责任人、快照是否失效，以及建议写回的最小状态增量；不要求使用者人工转发。视觉观察任务是更窄的临时角色：只返回本轮视觉结果卡和证据定位，不返回整批图片或接管建议，也不把观察到的表象直接升级为代码根因或专业结论。
