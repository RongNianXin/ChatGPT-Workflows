# 项目级配置迁移清单

本清单只在操作者另行要求“项目接入、项目配置迁移或修复项目控制面”时使用，不再随规则广播自动执行。规则加载成功不代表本清单已经执行；本清单存在缺口也不得降低规则加载结果。清单只描述需要检查的对象，不授权产品代码、远端或其他项目修改。

| 项目对象 | 空白项目 | 已运行项目 | 普通专项任务 | 核验结果 |
|---|---|---|---|---|
| `总指挥工作流/工作流启用声明.md` | 仅在操作者明确启用并任命总指挥后才提出新建并写入 `enabled` 的候选；否则只读并回 `WARN/UNKNOWN` | 检查并补齐（须有事件写入授权） | 只读 | |
| 动态状态索引 | 建立唯一 `CURRENT/HISTORY` | 收敛旧 CURRENT，保留历史指针 | 只读 | |
| 中央入口与待办/进度指针 | 按项目需要建立 | 核对路径、指纹和事实截点 | 只读 | |
| 规则版本与 manifest | 登记当前版本 | 刷新来源指纹 | 只读 | |
| 交接候选指针 | 尚无则登记空 | 保留旧候选为历史，只保留一个当前指针 | 只读 | |
| 分支任务关系 | 无 | 补 `parent_task_id -> current_task_id` | 只记录自身身份 | |
| 旧材料 | 无 | 标记 `LEGACY_UNVERIFIED`，不覆盖 | 只读 | |

缺失、冲突或无法写入时，只阻断依赖该对象的动作，并在回执中写明恢复条件；不得把无关产品任务全部判为阻断。
