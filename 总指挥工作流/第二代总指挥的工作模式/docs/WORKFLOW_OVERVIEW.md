# 工作流概览

本页只提供导航，不单独维护另一套规则摘要。本分类目录中的 `00`～`11` 是第二代工作流的唯一正式规则来源；如本页与编号文档不一致，以编号文档为准。

## 从哪里开始

1. 使用者只需打开 [01-操作者操作手册.md](../01-操作者操作手册.md)，按“首次使用 3 步”登记本地规则目录并选择场景。
2. AI 从 [00-第二代工作流总览.md](../00-第二代工作流总览.md) 读取当前版本、完整编号注册表和按需加载顺序。
3. 正常交接候选按 [总指挥轻量交接启动配置.md](../总指挥轻量交接启动配置.md) 核验；指纹异常时才展开对应正式规则。

本地操作者协作画像是可选功能：公开规范见 [11-操作者协作画像规范.md](../11-操作者协作画像规范.md)，真实画像与来源资料必须留在被 Git 忽略的本地路径；外发独立脱敏副本也必须经过两条独立操作者消息确认。

专项任务不是默认执行层。普通汇报按 [02 的标题级加载映射](../02-总指挥核心规则.md#标题级按需加载映射)读取 `03` 的汇报出口，不以创建专项为前提；只有确需新建专项任务时，才按净收益及授权门禁补读任务卡并创建最少量任务。使用者不需要向两个窗口重复描述或转发结果。

完整编号导航只在 `00` 维护，避免两份注册表漂移。公开信息、Secret、路径和来源项目隔离要求见 [SECURITY_BOUNDARY.md](SECURITY_BOUNDARY.md)；规则变更的通用事件格式见 [RULE_CHANGE_EVENT.md](../templates/RULE_CHANGE_EVENT.md)。

规则加载和压缩/恢复后的关键语义回读统一见 [10 自动检索与回退](../10-自动状态索引规范.md#5-自动检索与回退)，授权内连续执行见 [09](../09-自动化授权与风险分级.md#授权内连续执行与局部停止)。下列手册首次按触发条件完整读取，同任务后续按 10 复用；不把指纹、静态检查或合成样例当作真实执行保证。

## 辅助工具

- [自动化测试经验与可信结果门禁](AUTOMATED_TESTING_LESSONS.md)：浏览器、真实媒体、模型、跨版本对照或人工结果冲突时按需完整读取；它不产生测试、产品修改或远端写入授权。
- 有界自动测试、授权内修复与复测从 [01 场景 2G](../01-操作者操作手册.md#场景-2g用真实数据做有界自动测试修复和复测) 启动；本页不另设测试模板。
- [Pull Request 提交、更新与审查协作标准](PR_SUBMISSION_AND_REVIEW_STANDARD.md)：创建或更新 PR、请求审查、回复阻断意见和判断可合并状态时完整读取；它不产生远端写入、Approve 或 Merge 授权。
- [输入到输出链路排查与算法调优标准](PIPELINE_DIAGNOSIS_AND_ALGORITHM_TUNING_STANDARD.md)：2E 失败反馈先按 2.1 最小分流，确需完整 2C 时全文读取；内部逐节点核验，默认先报告原因证据、修复和验证，文本图或分步 HTML 按需展示。
- [链路分步演示 HTML 模板](../templates/PIPELINE_STEP_DECK_TEMPLATE.html)：用于把同一组稳定节点编号和实际证据做成可翻页说明；模板本身不生成中间证据，也不改变权限或验收状态。
- [链路分步演示增强器](../tools/pipeline-step-deck/PIPELINE_STEP_DECK_ENHANCEMENTS.js)：由构建脚本按需注入本地演示页，提供同源结构化复制、精确视觉折叠和带路径选择的完整长图导出；操作者仍只从 `01` 启动，不需要单独调用。
- [Codex 会话交接评估](../../../实用小工具/Codex会话交接评估/README.md)：只读检查本地会话文件容量、自动压缩次数和最近输入占窗口比例，辅助判断是否准备交接。
- 工具阈值属于本地经验规则，不替代任务阶段、交接断点和实际理解质量判断。
