# 跨项目经验库

**简体中文** | [English](README.en.md)

这里保存经过脱敏和审核、可以跨项目复用的总指挥工作经验。项目特有经验留在项目自己的本地经验库，不要直接复制到这里。

## 使用规则

1. 先读 [经验索引](经验索引.md)，只按当前任务主题加载相关条目；索引命中不等于获得读取或执行授权。
2. 新经验先写入 `候选/`，不得直接改公共索引。候选必须说明适用范围、前置条件、反例、证据类型、脱敏状态和失效条件。
3. 公共索引由当前登记的唯一维护者按版本校验和原子更新；冲突、租约失效或来源不明时停止公共索引写入，保留候选等待处理。
4. 本地 Commit、公共索引审核和远端 Push/PR 是三个独立动作；本地经验变化不会自动阻断其他项目，也不会自动获得远端发布授权。

## 目录

- [经验索引](经验索引.md)：可按需加载的短索引和状态定义。
- [候选模板](经验候选模板.md)：项目总指挥生成脱敏候选时使用。
- `候选/`：待审核的独立候选文件；不得把项目原始资料直接放入这里。
